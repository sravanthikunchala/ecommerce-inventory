**#  E-commerce & Inventory Management Platform

## Overview

It is a full-stack e-commerce and inventory management application featuring customer shopping workflows, administrative management, inventory operations, order processing and reporting.

## Technology Stack

**Frontend**
- React.js
- JavaScript (ES6+)
- React Router
- Axios
- Bootstrap 5
- Recharts

**Backend**
- Python
- Django
- REST APIs

**Integrations**
- Razorpay payment gateway
- Google OAuth
- MSG91 OTP verification
- AWS S3
- Shipway shipping and tracking

## Key Features

### Customer Module
- Customer registration and authentication
- Product browsing and search
- Shopping cart and wishlist
- Address management
- Checkout and payment
- Order tracking
- Customer profile management

### Admin Module
- Dashboard and reports
- Product and category management
- Customer management
- Role-based access
- Order management
- Discount management

### Inventory Management
- Material receipts
- Stock management
- Material transfer notes
- Purchase orders
- Inventory reports
- Excel imports and exports

## Project Structure

- frontend: React application
- backend: Django application

See the frontend and backend setup instructions for local development.
